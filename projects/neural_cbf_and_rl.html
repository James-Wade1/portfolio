Learning Control Barrier Functions and Navigational Controller for a 2D Single Integrator System

Graduate-level Deep Learning | Brigham Young University | 2025

This 30-hour final project explores learning control barrier functions (CBFs) and navigational controllers to achieve safe navigation in a 2D single integrator system.

For the control barrier functions, I trained ResNet architectures to learn the analytical CBF using data sampled in randomly generated environments with circular obstacles. This same environment also served as the learning environment for the PPO-based navigational controller, seeking to traverse the agent from its current location to the goal location in 2D space. To evaluate performance, I tested all combinations of three CBF approaches (analytical, MLP, and ResNet) with two controller types: an analytical straight-line controller and the PPO-based controller trained to replicate it. We measured outcomes across training loss, vector field visualizations, and generalization to unseen environments.

This independent research project taught me valuable skills in designing and training neural networks for control tasks, implementing reinforcement learning algorithms in efficiently designed environments, and evaluating system performance in dynamic environments. The results demonstrated the effectiveness of learned CBFs and controllers in ensuring safe navigation, highlighting the potential of combining deep learning with control theory for autonomous systems.

Future work could explore more complex environments, the different agent speeds noticed between the controller combinations, different agent dynamics, and advanced RL algorithms to further enhance navigation performance and safety.

Note: This project was completed as part of my graduate-level Deep Learning course at Brigham Young University in 2025. The main body of the report was limited to 2 pages.
